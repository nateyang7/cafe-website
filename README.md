# Snake en Python OOP
**Auteur**: Nathan YANG

## Présentation
Le Snake est un jeu qui se déroule sur une grille 2D où le joueur contrôle 
un serpent qui doit manger de la nourriture pour grandir. Le but étant 
de manger le plus de nourriture tout en gérant la croissance du serpent et 
les bordures de la grille.

## Structure
- snakegame : Code source
- docs : Documentations
- tests : Tests automatisés avec pytest
